# 🧭 Бізнес Компас

**Фінансовий директор, податковий помічник і бізнес-радник для українського ФОП у кишені.**

iOS-додаток на SwiftUI, який не просто показує новини й поради, а працює з *вашими* цифрами:
рахує податки, попереджає про строки, оцінює здоров'я бізнесу та моделює рішення до того, як ви їх ухвалите.

## ✨ Унікальні можливості

| | Функція | Що дає |
|---|---|---|
| 💓 | **Пульс бізнесу** | Інтегральний індекс 0–100 з чотирьох складових: запас міцності (runway), маржа, динаміка виручки, податкова безпека. Кожна складова пояснена, а інсайти підказують, що робити далі. |
| 🎛 | **Симулятор «Що якщо»** | Змінюйте обсяг продажів, ціни, витрати, наймайте людей, додавайте маркетинг — і бачте прибуток, податки, runway та **чи не вилетите ви з ліміту групи ФОП**. |
| 🏛 | **Податки без стресу** | Калькулятор 1–3 груп (єдиний податок, військовий збір, ЄСВ), шкала використання річного ліміту, персональний календар строків сплати й декларацій з орієнтовними сумами та позначками «сплачено». |
| 🎁 | **Гранти під вас** | Каталог програм підтримки («Власна справа», 5-7-9%, ветеранські гранти, Diia.City…) з **відсотком збігу** за галуззю, статусами засновника та розміром команди. |
| 💬 | **Бізнес-радник** | Чат, який знає ваші цифри: «Як справи в бізнесі?», «Коли наступний платіж?», «Чи варто змінити групу?». Працює офлайн; через протокол `AdvisorEngine` легко підключити LLM. |
| 💡 | **Валідатор ідей** | Оцінка ідеї за 6 зваженими критеріями з конкретними порадами щодо слабких місць. |

## 🎨 Дизайн

- Власна дизайн-система: синьо-жовта палітра, «живий» фон з розмитими плямами, скляні картки (`.ultraThinMaterial`).
- Плаваюча панель вкладок з анімованим індикатором (`matchedGeometryEffect`).
- Анімовані кільцеві індикатори, `contentTransition(.numericText())`, тактильний відгук (`sensoryFeedback`).
- Інтерактивні графіки Swift Charts з вибором місяця.
- Світла й темна теми, VoiceOver-мітки.

## 🔒 Приватність

Усі дані зберігаються **лише на пристрої** (JSON у Documents із `completeFileProtection`). Жодних акаунтів чи серверів.

## 🛠 Стек

- iOS 17+, Swift 5.9, SwiftUI, Observation (`@Observable`), Swift Charts
- XcodeGen для генерації проєкту
- XCTest для ядра бізнес-логіки

## 🚀 Запуск

```bash
brew install xcodegen
xcodegen generate
open UkrainianBusinessGuide.xcodeproj
```

Далі `Cmd + R`. На першому екрані можна обрати **«Переглянути з демо-даними кав'ярні»**, щоб одразу побачити всі функції.

Тести: `Cmd + U` або
```bash
xcodebuild test -scheme UkrainianBusinessGuide -destination 'platform=iOS Simulator,name=iPhone 15'
```

## 🤖 Автоматична збірка (без Mac)

Кожен push запускає GitHub Actions на macOS (`.github/workflows/ios.yml`):
збірка → юніт-тести → запуск у симуляторі iPhone → скриншоти всіх екранів (світла й темна теми).

**Як переглянути результат:** вкладка **Actions** у репозиторії → останній запуск «iOS збірка» →
внизу сторінки розділ **Artifacts**:
- `screenshots` — PNG кожного екрана;
- `BusinessCompass-simulator` — зібраний `.app` для iOS Simulator;
- `build-log` — журнал, якщо збірка впала.

Запустити вручну: **Actions → iOS збірка → Run workflow**.

**Відкрити `.app` на Mac:** розпакуйте архів, запустіть Simulator (`open -a Simulator`) і
перетягніть `UkrainianBusinessGuide.app` у вікно симулятора (або `xcrun simctl install booted UkrainianBusinessGuide.app`).

**На реальному iPhone** потрібен підпис Apple: безкоштовно — через Xcode з вашим Apple ID
(на 7 днів), або через TestFlight з платним акаунтом Apple Developer.

## 📐 Податкові параметри

Розрахунки базуються на `TaxParameters.y2026`: мінімальна зарплата 8 647 ₴, прожитковий мінімум 3 328 ₴.
Ліміти доходу: 167 / 834 / 1 167 мінімальних зарплат для 1 / 2 / 3 групи. ЄСВ — 22% мінімальної зарплати,
військовий збір — 10% мінімальної зарплати (1–2 група) або 1% доходу (3 група).
Щороку достатньо оновити одну структуру. Розрахунки орієнтовні й не замінюють консультацію бухгалтера.
