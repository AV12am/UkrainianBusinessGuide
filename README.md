# Український Путівник у Бізнесі - iOS Додаток

**Українська мобільна платформа для початківців у сфері бізнесу та інвестицій**

## 📱 Про Додаток

Мобільний iOS додаток, який допомагає українським підприємцям та інвесторам:
- Досліджувати українські бізнес-компанії
- Слідкувати за найважливішими новинами галузі
- Отримувати корисні поради та стратегії
- Аналізувати дані в реальному часі

## ✨ Основні Можливості

### 1. **Навігація по Компаніях** 🏢
- Пошук за категоріями (IT, Торгівля, Виробництво, Фінанси тощо)
- Детальні профілі компаній
- Рейтинги та відгуки
- Контактна інформація

### 2. **Новини та Тренди** 📰
- Свіжі новини про українських підприємців
- Аналіз ринку
- Оновлення регулювання
- Персоналізовані новини за інтересами

### 3. **Поради та Навчання** 💡
- Статті про стартапи та бізнес-планування
- Поради від експертів
- Керівництво для початківців
- Кейс-студії успішних проектів

### 4. **Аналітичні Дані** 📊
- Графіки ринкових показників
- Курси валют у реальному часі
- Аналіз трендів галузей
- Порівняльна статистика

## 🛠 Технологічний Стек

- **iOS 14.0+**
- **SwiftUI** - інтерфейс
- **Combine** - реактивне програмування
- **CoreData** - локальне сховище
- **URLSession** - мережеві запити

## 🚀 Швидкий Старт

1. Клонуйте репозиторій
2. Відкрийте `UkrainianBusinessGuide.xcodeproj` в Xcode
3. Натисніть Run або натисніть `Cmd + R`
