# Публікація в App Store і TestFlight

Усе технічне вже в репозиторії: іконка, маніфест приватності (`PrivacyInfo.xcprivacy`), ключ про шифрування, опис для App Store Connect нижче. Від вас потрібні акаунт розробника й кілька кліків.

## 1. Акаунт Apple Developer

1. Зареєструйтеся в Apple Developer Program на developer.apple.com/programs: 99 $ на рік. Можна як фізособа, можна як організація (для ФОП зазвичай достатньо фізособи).
2. Для продажу в ЄС Apple попросить вказати статус трейдера (DSA). Для безкоштовного застосунку від ФОП це, як правило, «трейдер» з адресою й контактами ФОП.

## 2. Ідентифікатори

У розділі Certificates, Identifiers & Profiles:

| Що | Значення |
|---|---|
| App ID застосунку | `ua.businesscompass.app`, увімкнути App Groups |
| App ID віджета | `ua.businesscompass.app.widget`, увімкнути App Groups |
| App Group | `group.ua.businesscompass.app`, додати до обох App ID |

Якщо `ua.businesscompass` уже зайнятий, змініть префікс у `project.yml` (`bundleIdPrefix`, `PRODUCT_BUNDLE_IDENTIFIER`) і App Group у `project.yml` та `Shared/WidgetSnapshot.swift`.

## 3. Підпис і збірка на Mac

```bash
brew install xcodegen
xcodegen generate
open UkrainianBusinessGuide.xcodeproj
```

1. Для цілей `UkrainianBusinessGuide` і `BusinessCompassWidget`: Signing & Capabilities, Team: ваш акаунт, Automatically manage signing.
2. Щоб не обирати Team після кожної генерації, додайте в `project.yml` у `settings.base` рядок `DEVELOPMENT_TEAM: ВАШ_TEAM_ID`.
3. Оберіть пристрій «Any iOS Device (arm64)», потім Product, Archive.
4. В Organizer: Distribute App, App Store Connect, Upload.

## 4. TestFlight

1. appstoreconnect.apple.com, Мої застосунки, «+»: назва, мова «Українська», Bundle ID `ua.businesscompass.app`, SKU `business-compass`.
2. Через 15–30 хвилин після завантаження збірка з'явиться у вкладці TestFlight.
3. Внутрішні тестувальники (до 100 людей з вашої команди App Store Connect) отримують збірку одразу.
4. Для зовнішніх тестувальників (до 10 000, за посиланням) Apple спершу проводить Beta App Review, зазвичай до доби.

## 5. Сторінка в App Store

**Назва** (до 30 символів): Бізнес Компас: ФОП і податки

**Підзаголовок** (до 30): Податки, строки, рахунки

**Категорія:** Фінанси; додаткова: Бізнес. **Вік:** 4+.

**Ключові слова** (до 100 символів, через кому без пробілів):

```
ФОП,єдиний податок,ЄСВ,декларація,рахунок,бухгалтерія,гранти,бізнес,monobank,облік,ліміт
```

**Опис:**

> Бізнес Компас рахує податки ФОП, нагадує про строки і показує, скільки грошей справді ваші.
>
> Податки без калькулятора. Єдиний податок, військовий збір і ЄСВ для 1, 2 і 3 груп за ставками 2026 року. Календар строків сплати й декларацій з орієнтовними сумами і нагадуваннями.
>
> Виписка з банку за хвилину. Підключіть monobank особистим токеном або завантажте CSV з будь-якого банку. Категорії підберуться самі, дублікати пропустяться.
>
> Рахунки з QR-кодом. Створіть рахунок, надішліть PDF, клієнт оплачує, навівши камеру на QR-код НБУ. Оплачений рахунок сам потрапляє в доходи.
>
> Податкова скарбничка. Скільки відкласти з кожного доходу й скільки має лежати на податки зараз.
>
> Ліміт групи під контролем. Шкала використання річного ліміту і попередження до того, як доведеться міняти групу.
>
> Дані для декларації. Дохід наростаючим підсумком і податки по кварталах, як у формі в Електронному кабінеті.
>
> Гранти й програми. «Власна справа», 5-7-9%, ветеранські програми, Дія.City з відсотком відповідності вашому бізнесу.
>
> Відкриття ФОП крок за кроком: від КВЕД до першої сплати податків.
>
> Приватність. Жодних акаунтів і серверів: усі дані лише на вашому телефоні, вхід через Face ID.

**URL політики конфіденційності:** посилання на `PRIVACY.md` у репозиторії (репозиторій має бути публічним) або ту саму сторінку на GitHub Pages.

**Конфіденційність застосунку (App Privacy):** «Дані не збираються» (Data Not Collected).

**Шифрування:** у збірці вже є `ITSAppUsesNonExemptEncryption = NO`, питання про експорт шифрування не з'явиться.

## 6. Скриншоти

App Store вимагає скриншоти 6,9″ (1320 × 2868) або 6,5″. CI знімає на найновішому звичайному iPhone (6,3″). Для сторінки в App Store змініть у `scripts/pick-simulator.py` модель на «Pro Max», запустіть збірку вручну (Actions, iOS збірка, Run workflow) і завантажте кадри з гілки `ci-screenshots`.

## 7. Перевірка перед відправкою

- [ ] Збірка проходить на реальному iPhone: віджет додається, Face ID вмикається, PDF рахунку ділиться.
- [ ] Реквізити й токен monobank не з демо-даних.
- [ ] Номер версії (`MARKETING_VERSION`) і збірки (`CURRENT_PROJECT_VERSION`) у `project.yml` збільшені.
- [ ] У нотатках для рецензента Apple пояснено, що токен monobank необов'язковий, а всі функції можна перевірити на демо-даних з онбордингу.
